# Dữ liệu dùng: Đặc tả 003

- Candidate: `region`, `province`, `is_deleted`.
- Recruiter: `status`, `is_deleted`, `current_workload`, `max_workload`.
- RecruiterRegion: `region`, `province`.
- RecruiterCampaign và Campaign: trạng thái liên kết/campaign.

Không sử dụng `full_name`, `phone`, tuổi hay giới tính để lọc hoặc xếp hạng.
