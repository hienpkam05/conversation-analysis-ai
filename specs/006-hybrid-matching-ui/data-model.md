# Dữ liệu 006

Không thêm bảng mới. Spec đọc:

- `candidates` để chọn ứng viên.
- `recruiters`, `recruiter_regions`, `recruiter_campaigns`, `campaigns` qua hard filter.
- `model_versions` để xác nhận model active.
- Qdrant recruiter/campaign collections để lấy semantic scores.

`matching_runs` và `matching_results` được giữ cho Spec 007, nhằm tránh ghi dữ liệu thực nghiệm chưa hoàn chỉnh.
